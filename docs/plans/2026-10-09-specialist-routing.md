# Deterministic specialist routing and related work units

Issue #50

## Scope
Opt-in trusted path rules activate performance/concurrency, data-integrity/migrations,
and configured domain procedures. Preserve configured reviewers and correctness/security
fallback, shared immutable context, source attribution and fixed total token accounting.
No model delegator or default promotion; quality comparisons belong to #51.

## Assumptions
- Rules consume selected captured current/previous paths, never executable repository policy.
- Manual force selection can override specialist activation, never remove existing reviewers.
- Related groups are inspectable focus annotations; every reviewer retains the global read root.
- Explicit group selectors bind implementation/callers/contracts/tests; automatic grouping uses
  normalized basenames and records its heuristic rather than claiming dependency discovery.
- Existing ledger fairly divides the fixed ceiling across actual reviewers and any chair.
- Specialist YAML is a versioned packaged procedure; caller inline definitions preserve identity.
