# Nare 2026.11.107: pin

## Goal and design

Move the pinned runtime from nare 2026.11.100 to 2026.11.107 (#128), the first
step of making self-hosted inference a production rail (#137). The rules of
[the 2026.11.100 plan](2026-11-12-nare-2026-11-100.md) stay: the subprocess
boundary, capabilities read from `nare contract`, and nothing that changes what a
default-configuration review sends or how its verdict is derived.

No live model call, credential, holdout content or deployment is part of this
work. Every proof runs offline against the installed 2026.11.107 console.

### What the release range changes

nare `2026.11.100..2026.11.107`, contract version 3 throughout:

- 101 (nare #300): `nare contract` gains a `compaction` entry with the built-in
  default mode, trigger and target. Scrutare already sends `--compaction elide
  --compaction-trigger 0.8 --compaction-target 0.6` on every contract 3 session,
  so no default reaches a review. A new installed test compares the advertised
  defaults with those values, so a release that moves one is noticed at the pin.
- 102 (nare #296): `--check-command` and `--check-timeout`, a caller's argv as an
  in-session answer check. Filed for Scrutare's citation validation; adopted in
  #130, not here.
- 103 (nare #297): `--cited-read-map`. Also for #130.
- 104 (nare #298): evidence only.
- 105 (nare #309): typed caller-tool outcomes. Scrutare offers no caller tools.
- 106 (nare #311): an optional `diagnose=` callback on the native loop, whose
  errors join schema errors in one correction. Library only; a caller without it
  keeps its behavior, and `nare run` sets none, so a Scrutare session is
  unchanged.
- 107 (nare #313): `--structured-output` accepts `json_object` and `tool_call` on
  the openai rail, and a domain correction restores approved tools. Scrutare's
  inspection still offers only `json_schema` until #131.

A session that sets none of these options sends the same argv as on 2026.11.100.

## Note for local runs

uv writes a `/bin/sh` wrapper instead of a direct shebang for a console whose
interpreter path is longer than the kernel's shebang limit. The offline
installed tests read the console's shebang to find its interpreter, so install
the pinned nare at a short path (for example with `UV_PROJECT_ENVIRONMENT`).
