# Independent bounded semantic assessment

Issue #47

## Scope
In: opt-in independent assessment of immutable v2 candidates, shared preallocated
review tokens, preserved counterevidence and dispositions, code-derived policy,
strategy composition, read-only replay, and installed runtime verification.
Out: formal proof, quality promotion, and live App deployment. Comparative quality
requires the evaluation/report issues; no claim of improved precision is made here.

## Assumptions
- Approved nine-issue backlog and unattended worktree/subagent shipping authorize
  implementation without further design approval ceremonies.
- One separate assessor batch is bounded by its reserved token quota and runtime;
  complete unresolved blocking claims escalate as semantic uncertainty after this
  one-attempt bound. Technical failures/partial output withhold a verdict.
- Supporting and counter citations bind captured bytes, not assertion truth.
- Supported candidates cannot be erased by a majority or chair selection.
- Legacy configuration, runtime, output and replay remain unchanged.

## Tasks
- [ ] 1. Configure explicit reserved allocation: opt-in requires v2, allocation
  cannot exhaust discovery, fair discovery quota excludes assessor reservation.
- [ ] 2. Parse immutable supported/refuted/unresolved assessments: exact candidate
  coverage, closed fields, checked citations and retained independent rationale.
- [ ] 3. Execute assessor through shared nare lifecycle: typed schema, session
  reconciliation, accounting and private raw evidence; incomplete results withhold.
- [ ] 4. Compose panel/debate/iterative: supported minority retained, refuted
  excluded with reasons, unresolved blocking escalates without silent approval.
- [ ] 5. Replay recorded policy/citations/dispositions without asserting truth;
  safe posting, installed wheel/nare and legacy regression checks; documentation.

## Review focus
Missing/duplicate/unknown candidates; fabricated validation labels; contradictory
citations; discovery overshoot; incomplete assessment; empty candidates; stale
iterative history; chair deletion/category downgrade of a supported blocker;
replay tampering and captured config disagreement.
