"""Render only the new public report from its offline-verified summary."""
import json
import sys
from pathlib import Path

p = Path(sys.argv[1])
read = lambda name: json.loads((p / name).read_text())
s = read('summary.json')
j = s['jobs']['g4']
sessions = s['session_causes']['g4']
c = sessions['corrections']
provider = s['provider']['g4']
evidence = read('provider-evidence.json')
prep = read('g4/preparation.json')
mechanical = read('g4/mechanical-qualification.json')
amendment = read('g4-amendment.json')
max_attempt = max(a['tokens'] for cell in mechanical['cells'] for a in cell['attempts'])
smoke = read('smoke-summary.json')

def table(headers, rows):
    return '\n'.join(['| ' + ' | '.join(headers) + ' |',
                      '| ' + ' | '.join('---' for _ in headers) + ' |'] +
                     ['| ' + ' | '.join(str(v).replace('|', '\\|') for v in row) + ' |'
                      for row in rows])

gate_rows = []
for title, key, denominator in [
    ('Complete and accounted', 'cells_complete_and_accounted', 36),
    ('Complete and accounted on first attempt', 'cells_complete_and_accounted_first_attempt', 36),
    ('Aggregate defect cells with non-empty valid v2 evidence', 'aggregate_defect_cells_nonempty_valid_v2', 6),
    ('Assessed defect cells with an actual complete assessor', 'assessed_defect_cells_actual_complete_assessor', 6),
]:
    gate_rows.append([title] + [f"{s['jobs'][label]['gate_items'][key]}/{denominator}"
                              for label in ('g4', 'g3', 'c1', 's2')])
gate_rows.append(['Every attempt within the 200,000 ceiling'] +
                 ['pass' if s['jobs'][label]['tests']['all_attempts_within_ceiling'] else 'fail'
                  for label in ('g4', 'g3', 'c1', 's2')])
gate_rows.append(['Transient rerun attempts'] + [s['jobs'][label]['rerun_attempts']
                                               for label in ('g4', 'g3', 'c1', 's2')])
verdict = 'passed' if s['qualified'] else 'did not pass'
lines = [f'''# GLM 5.3 Flash qualification with protocol correction — g4

The gate was [frozen on #51 before launch](https://github.com/ViviDynamics/scrutare/issues/51#issuecomment-6472089607). All 24 declared criteria/profile fields and the pass-rule string are byte-identical to g3/c1; all 23 corpus input hashes match. The actual published Scrutare **{prep['release_tag']}** wheel comes from `{prep['source_commit']}`. Its SHA-256 is `{next(v for k, v in prep['input_sha256'].items() if k.endswith('.whl'))}`.

The profile retains g3's `context.line_counts: true` and `findings.citation_correction: true`, adding `findings.protocol_correction: true`. Protocol correction takes precedence: a session receives at most one correction. The model supplies a complete replacement answer for deterministic protocol defects; unchanged validation decides acceptance. The engine never drops, clamps or inserts findings, lines or candidate IDs. A still-invalid or unanswered correction fails its session and cell and remains in the 36/36 gate.

Other settings remain unchanged: three pilot development cases; aggregate/assessed/focused1/focused3; three repeats; 200,000 review ceiling; 50,000 assessor reservation; 37,500 discovery grants (50,000 aggregate); 20,000 per-request output cap; `json_schema`; nare 2026.10.12; six initial native turns plus at most one eligible bounded correction; concurrency 3; 1800 s session timeout; no overrun fallback. Every attempt is retained. A cell needing a transient provider rerun fails the first-attempt item. Protocol refusals and `model_repetition` are ineligible for transient reruns.

The gate allows g4 plus at most one prospective re-test, only on explicit maintainer approval and a newly posted freeze. No re-test was run. The frozen launch condition requires no idle window under the maintainer's 2026-10-25 (#96) and 2026-10-28 (#99) instructions and the [c1 precedent](https://github.com/ViviDynamics/scrutare/issues/51#issuecomment-6340502541). g4 launched at **{evidence['launch']['started_utc']}** as `scrutare-glm-g4.service`, with separate load and finish-evidence units.

## Gate results

{table(['Criterion', 'g4', 'g3', 'c1', 's2'], gate_rows)}

g4 status counts: `{json.dumps(j['status_counts'], sort_keys=True)}`. The matrix contains {j['gate_items']['cells']} cells; clean cells complete: {j['clean_cells_complete']}/12. Maximum recorded attempt: {max_attempt:,} tokens. Discussion rounds attempted/completed: {mechanical['discussion_attempted_rounds']}/{mechanical['discussion_completed_rounds']}.

## Failed cells
''']
if s['gate_losses']:
    lines.append(table(['Cell', 'Causes / failed gate items'],
                       [[f"`{r['cell']}`", ', '.join(f'`{v}`' for v in r['causes'])]
                        for r in s['gate_losses']]))
    lines.append('\nFailed native sessions:\n')
    for r in sessions['failed_sessions']:
        lines.append(f"- `{r['cell']}`, attempt {r['cell_attempt']}, `{r['persona']}`: `{r['cause']}` (`{r['reason']}`).")
else:
    lines.append('None. Every cell met the frozen gate.')
lines.append('''

The cap stopped the request before an acceptable final answer; no correction was offered, and assessment did not run after failed discovery.

''')

    lines.append(table(['Defect type', 'Corrected', 'Refused', 'No answer', 'Failed'],
                       [[f'`{kind}`'] + [outcomes.get(k, 0) for k in ('corrected', 'refused', 'no_answer', 'failed')]
                        for kind, outcomes in sorted(c['sessions_by_type_and_outcome'].items())]))

    lines.append(table(['Session', 'Types', 'Outcome', 'Tokens'],

                   [[f'`{key}`', value['rows'], value['prompt_tokens'], value['completion_tokens']]

## Reproduce and limits

Run `python3 reproduce.py --output g4-summary.json` with Python 3.10 or newer. It uses only the standard library and the immutable g3, c1 and s2 sibling packages. It verifies the public manifest, posted freeze and amendment hashes, amendment timing, unchanged criteria/corpus/settings, mechanical cells, session corrections/accounting, smoke cancellation accounting and serving/load evidence. It refuses a differing summary. `extract-sessions.py` can regenerate session metadata from retained private captures without provider calls.

Private native captures and raw proxy reads remain private and are represented by hashes. Public exports cannot independently authenticate the provider or establish semantic truth. Personal aliases/emails, keys/hashes, client IPs, request content and transcripts are excluded. Runs on different days/releases and concurrent loads provide a side-by-side comparison, not a paired causal estimate. Backend model revision is unverified. These pilot cases do not establish general reliability. Zero actual human judgments were added. The holdout remains unopened. No defaults, promotion, App, infrastructure or deployment changes were made. #51 remains open.
''')
